# Fixtures

<details>
<summary>日本語</summary>

`good/`には現在のpolicyに従う出力を、`bad/`には繰り返し起きる失敗例を置きます。
現時点では人が読むfixtureです。機械可読形式や自動で強制されるchecker contractはまだ
定義しません。

</details>

`good/` contains output that follows the current policy. `bad/` contains output
that exposes a recurring failure mode. The fixtures are human-reviewed examples
for now. They do not establish a machine-readable format or an automatically
enforced checker contract.
