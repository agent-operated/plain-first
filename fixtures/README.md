# Fixtures

<details>
<summary>日本語</summary>

`good/`には現在のpolicyに従う出力を、`bad/`には繰り返し起きる失敗例を置きます。
現時点では人が読むfixtureです。schemaや自動checkerのcontractはまだ定義しません。

</details>

`good/` contains output that follows the current policy. `bad/` contains output
that exposes a recurring failure mode. The fixtures are human-reviewed examples
for now; no schema or automated checker contract is implied.
