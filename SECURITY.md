Plain First currently contains policy text, examples, and fixtures. It has no
executable runtime. If a future change introduces executable content, do not
assume this statement still describes that release; check the exact revision.

Report a security vulnerability through GitHub's private vulnerability
reporting for this repository. Do not include exploit details or sensitive
information in a public issue.

Use a public issue for policy wording, examples, fixtures, and other reports
that do not expose a security vulnerability.
